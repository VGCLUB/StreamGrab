抖音与小红书使用上游解析器公开测试样例进行无 Cookie 探测，均要求登录 / 安全验证，程序已显示更新 Cookie / 保留完整分享参数的提示。尚未使用用户登录信息验收这两个平台的实际视频和图文下载。正文图片解析逻辑已用结构化页面样例验证，下载机制已用本机 HTTP 图片验证。

## 交付与边界

免安装目录附带 FFmpeg / FFprobe、动态 Qt 库、第三方许可证和应用源码。当前裁剪先下载全源再导出，不节省完整源文件的下载流量。受平台频控、登录状态和解析器版本影响，不能承诺每条链接均成功。未标记水印的源也可能含原片标识。

构建时发现宿主 PATH 的 Poppler ICU 被误收入发行包，与 Qt 6.12 所需 Windows 系统 ICU 的导出函数不兼容。已在 `.spec` 中排除额外 ICU，保留 Windows 系统加载路径；修复后的独立 exe 已实际启动并成功解析同一 B站链接。

发行包 `_internal/assets/ffmpeg` 下的 FFmpeg / FFprobe 已用绝对路径独立运行，通过 0.4 秒合成视频的编码与探测检查，不依赖 PATH 中的 FFmpeg。后续发行版桌面自动化遇到 `window bounds changed; call get_window_state before using this window`，刷新后的重试仍失败，已停止进一步 UI 输入；发行版未额外声称完成新的端到端下载测试。源码版的真实视频 / 音频下载与发行版启动、解析、内置媒体工具均已分别验收。
