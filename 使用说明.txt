拾流 · 视频与图文下载器 1.2.0

免安装版：完整解压 ZIP 后，双击“拾流下载器.exe”。请保留旁边的 _internal 文件夹。

用法：粘贴链接 → 解析 → 选择视频 / 音频 / 全部图片 → 选择保存位置 → 下载。

先直接解析公开视频或图文，不需要预先导入 Cookie。旧版 Edge 登录读取失败时，抖音 / 小红书会继续尝试公开内容解析；已在软件独立窗口登录的资料可以自动复用。

画质：只显示当前源站真实返回的分辨率。需要更高画质时可在“登录设置”为相应平台完成网页登录。

时间段：勾选“只下载指定时间段”，输入起止秒数，例如 12.5 到 30；也可输入 01:30。结束留空表示到结尾。当前先下载完整源文件，再精确裁剪。

音频：支持 MP3 / M4A / WAV / FLAC。图文：全部正文图片按顺序保存，可同时打包 ZIP。

录制备用（实验性）：解析 / 下载失败但网页能正常播放时，点击链接旁“录制备用”，选择视频或仅音频与起止时间。后台实际播放并保存播放器音画，耗时约等于片段时长，使用网页当前画质；不录整个桌面或麦克风。
网页播放器必须允许捕获；受保护媒体、跨域限制或持续缓冲可能使录制不可用。网站要求登录或验证时，先在“登录设置”的独立窗口完成。原片水印会保留，时间点受播放器与编码精度影响。录制期间可使用其他桌面窗口。

简单登录：左下角“登录设置” → 选择平台 → “打开网页登录” → 在网页中扫码或登录 → “我已登录，完成同步”或“保存设置”。
软件会自动返回工作台并重新解析已有链接。默认在本机加密保存状态，有效期内下次无需再次导入 Cookie。
登录窗口使用独立的 Edge / Chrome 资料，因此首次需要在此窗口登录。日常浏览器已有的登录不会自动迁移。
抖音会自动在后台读取播放源，并复用此前在独立窗口完成的登录，窗口已关闭也能恢复。需要本机已安装 Edge 或 Chrome。
原来的文件导入、粘贴 Cookie 和读取日常浏览器保留在“高级导入”里。
小红书：请使用完整分享链接，保留 xsec_token。安全验证需自行在登录窗口完成。

水印：优先使用未明确标记平台水印的播放源；原片内已编码的水印会保留。

任务：支持排队、取消、下载记录与打开结果。同名文件自动编号；未完成的图集不会标记为成功。

默认保存：用户 Downloads\拾流下载，可自行更改。
设置与历史：%LOCALAPPDATA%\StreamGrab。

验证范围：B站已做真实链接与片段下载验证；抖音已用真实作品在后台下载 2160×3840 视频，并导出 1–4 秒 MP3，时长 3 秒。小红书真实账号下载及抖音真实图集尚未验收。

具体功能、访问条件、开发说明与许可证见 README.md。
